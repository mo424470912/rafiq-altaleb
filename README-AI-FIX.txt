إصلاح المساعد الذكي وخطة المذاكرة

1) تم تحديث نموذج Gemini إلى gemini-3.5-flash-lite.
2) تم تحسين رسائل أخطاء API.
3) تم تفعيل إخراج JSON لخطة المذاكرة والاختبارات، لتقليل أخطاء تحليل الرد.
4) إذا ظهر خطأ 401/403، أنشئ مفتاح Gemini جديداً في Google AI Studio وضعه في GEMINI_API_KEY داخل index.html.
5) لا تشارك مفتاح API مع الآخرين، ويفضل تقييده أو نقله إلى خادم/Cloud Function قبل نشر التطبيق للعامة.
